## [0.6.0] - 2026-11-15

### Added

- generate release sections from commits
- **cli:** add --explain to print why each commit is in or out
- **config:** say which kind of config error it is, and test config end to end
- **tui:** open the editor by default at a terminal, and drop settings that did nothing

### Fixed

- **changelog:** repair the 0.2.0 section written by an offset bug
- **plan:** clear [Unreleased] before splicing, and test the ordering
- **version:** derive from the higher of the manifest and the newest tag
- **ci:** pin LF line endings, and never tag before the push can happen
- **tui:** give the editor a working Windows build
- **tui:** open the Windows console by name, not as an absolute path
- **git:** never let an inherited GIT_AUTHOR_* name the release commit
- **git:** ignore GIT_AUTHOR_* when committing

### Documentation

- clarify what --quiet suppresses

### CI

- test on three platforms and release with chgl
- stop the release workflow re-triggering on its own release commits

### Tests

- round-trip real-world changelogs, and normalise body line endings

### Maintenance

- **changelog:** drop the 0.1.1 section left by the version bug
- stop tracking python bytecode
- **changelog:** drop the orphan 0.3.1 section and fold its entry into 0.3.2
